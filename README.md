# covid-vaccination-data-pipeline
# 🚀 COVID-19 Vaccination Data Pipeline

## 📌 Project Overview

This project demonstrates a complete **data preprocessing pipeline** using Python and Scikit-learn.
The pipeline automates data cleaning, transformation, and preparation for machine learning.

Dataset used: COVID-19 World Vaccination Progress

---

## ⚙️ Technologies Used

* Python
* Pandas
* NumPy
* Scikit-learn
* Joblib

---

## 🔄 Pipeline Workflow

1. Data Collection using Kaggle dataset
2. Data Cleaning (handling missing values)
3. Feature Transformation

   * Numerical scaling
   * Categorical encoding
4. Pipeline creation using Scikit-learn
5. Model training (Linear Regression)

---

## 📊 Target Variable

* `daily_vaccinations`

---

## 🧠 Model Used

* Linear Regression (for prediction)
